## 1. 研究依据（为什么选这些改进，而不是堆功能）

### 1.1 工作区三份研究文档的硬约束

| 来源 | 与本版直接相关的结论 | 本版怎么落 |
| --- | --- | --- |
| 《人类大脑记忆功能的具体表现与原理》 | 情景记忆易受干扰、语义记忆较稳定，两者应分开建模；艾宾浩斯遗忘先快后慢；NREM 慢振荡/纺锤波/尖波涟漪驱动海马→新皮层转移，REM theta 波峰稳定新记忆、波谷去强化 | **强项，刻意不动**：五档 tier、七因子保留度、双相巩固、`decayState` 单一入口全部保持逐位兼容 |
| 同上 | Cowan 修正工作记忆容量为约 4 个组块（3–5） | **强项，刻意不动**：4±1 槽位竞争 + ignition 阈值 |
| 同上 | Bartlett：记忆是**建构性重构**；Loftus 仅改提问动词就能衍生不存在的细节；DRM 范式让被试自信误认未出现的词 | 这正是"确定性写入 + 结构化渲染 + 显式拒答"的价值。本版 F8（残差损坏不把压缩字节冒充原文）、F13（写入侧不跨边界取代）、含蓄句低置信弃权，都是**不制造新细节**这条原则的延续 |
| 《AI 意识与情感的神经基础与工程路径》 | Barrett 建构论四步（身体变化→感知→结合经验解释→情绪出现）；内感受是真实计算量；获取意识 ≠ 现象意识 | 项目的 interocept→appraise→coreAffect→label 管线与之对齐。本版只修**感知层**的输入质量（词边界/否定/含蓄），不改状态机与边界声明（不输出"我感到…"、危机轮挂起陪伴层） |
| 同上 | 语用/反语属于"结合经验解释"这一层，词表法在原理上就够不到 | 本版对"我没事/还好吧/你说呢"选择**弃权 + 标记**，而不是硬判一个情绪标签。宁可承认不确定，不编造"用户心情不错" |
| 《MnemoVault-DSH 记忆与情感插件开发文档》 | 端口/宿主契约、配置 schema 由宿主解析 | F2 的根因正是"宿主解析"这一假设在 devkit/harness 路径不成立；修复遵守项目既有契约：依赖宿主上下文的默认值在 `apply()` 里解析 |

### 1.2 同类项目与公开基准的对照（引自评判报告第 12/16/19 节，未做未核实的外部断言）

- 报告第 16 节已给出与 Mem0 / Zep / Letta 的逐项对比表（存储格式、双时态、遗忘、再巩固、情感状态、依赖、成本模型）。
- 报告第 19 节把 **C3 公开基准（LoCoMo / LongMemEval）、C4 基线对照、C6 第三方红队、C7 私有集**列为 P0，并指出"没有它们，前三件事的收益都无法证明"。
- 本版能补的是**评测基础设施与机制验证**（八节确定性验证 + CI 门槛 + Cov 首次量化），
  **补不了**的是公开基准接入、第三方红队、采购方私有集——这些需要外部数据与外部执行者。
  因此本版明确把它们留在"未完成"清单，而不是写一个自称等价的自建测试来充数。
- 数据可携带（E6）与多租户隔离（红线 1）是同类产品公开形态里的常见要求。本版补的是：
  机器可读全量导出、写入侧隔离、跨进程锁、备份/恢复工具化。

## 3. 本版实测抓到、评判报告未列出的三个缺陷

这三条是"跑起来才知道"的，代码审读很难发现，也是本版最值得记录的部分：

1. **F2（安全红线）**：`createHarness()` 里 `affect.config` 实测为
   `{ crisisEnabled: undefined, minorGuardEnabled: undefined, coeff: undefined }`。
   也就是说报告里"危机干预机制完备"的复现，是在**危机识别关着**的环境下跑的。
   根因是 devkit 传手写配置、不经过 schemastery 解析；修复放在 `affect.apply()` 消费端。
2. **F1（数据丢失）**：`purge({kind:'cell'})` 内部把目标映射成 `{kind:'all'}`，
   `/mnemo purge cell <id> --yes` 会清空全库 session_log / 快照 / 驱逐记录 / 来源映射。
   回执却只报"已删除 1 条 cell"，用户无从察觉。
3. **F13（写入侧污染）**：新增的 C8 压测第一次运行就失败——`ownHits=[0,1]`。
   追下去发现 B 会话的写入把 A 会话的 cell 标成了 `tInvalid`：冲突检测只看槽位不看归属。
   检索隔离（v0.7.0 的红线 1 修复）**没有覆盖写入侧**。

三条都有 `test/v072-fixes.test.mjs` 里的回滚即变红断言。

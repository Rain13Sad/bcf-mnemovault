# v0.6.1 — 把「说了在做、其实没做」清零

> 发布日 2026-11-01 · 基线 v0.6.0（`849de37`）· 265 测试 · 11 个 npm 包
> 完整方案：[`docs/design/V0.6.1-PLAN.md`](../design/V0.6.1-PLAN.md)

## 一句话

补丁版。不引入新能力，不改存储布局（MC03 不变，旧库不需要 rebuild）——
只把 v0.6.0 里**宣称与实现之间的缺口**补上。

## 两条"说了在做、其实没做"

| 宣称 | 0.6.0 的实际情况 | 0.6.1 |
| :--- | :--- | :--- |
| 每轮注入有价格上限 | 闸门只 push 了一条原因字符串。`maxPrice=0` 时仍发 10 条 / 319 token / ¥0.0057 | 闸门**真的裁剪**；连图例都承担不起时一条不发（`suppressed=true`） |
| 适配常用大模型 | `deepseek-v3` / `gpt-5` / `claude-sonnet-4-5` 全落保守档 → 强制 prose → token 2.5× | 32 个真实模型名全部命中；厂商家族有显式默认档；未知模型不再按免费计价 |

这两条都是被**断言错东西**的测试放过去的：它们检查 `fits=false` 和 `reasons` 里有"价格"两个字，
却没有检查 `rows` 有没有真的变少。这一版把测试纪律写进了计划文档 §5：

> 凡 `reasons` 里写了"按 X 裁剪"，就必须有一条断言证明 X 真的变了。

## 三条"悄悄做错"

- **删除回执说谎**：hard 删除会级联删边，回执却报删除前的数量。用户拿到 `danglingEdges: 5`
  会以为数据不一致。现在 hard 报 0（真相），soft 报删除前（归档层保留关系）。
- **`reembed()` 绕过向量索引**：它直接写 cell，索引里留着旧空间的向量，而自愈判据
  （`count` 不一致）永远不成立。现在走 `memory.reindexCell()`；中途失败可检测——
  inflight 标记带目标空间，`status().limits` 与 `doctor()` 都会报；换 provider 时游标归零。
- **英文情感是死的**：`I am happy` 得 0 分（相对 v0.2 是退化）。词表 +45 条，
  否定改词边界 + `n't` 后缀规则，强度词不再误伤 `太阳` / `超市` / `太空`。

## 一处审计稿判断错了

星图冷层漂移。审计稿说 `project3` 没展开 32 维向量，建议改用 `expandEmb`。实测：

| 方案 | 12 条真实记忆的平均漂移 |
| :--- | ---: |
| 零填充（v0.6.0 的实际行为） | **0.031** |
| `expandEmb`（审计稿建议） | **0.467** |

因为 `pq32` 是"前 32 维的 4 bit 量化"，零填充才是它的忠实逆变换。
最终保留零填充，把错注释改成事实，并加了一条反例断言——谁改回去就会红。

## token 口径

现在同时报两个数：`116.9`（启发式上界，CI 门槛用它）与 `105.4`（DeepSeek 校准口径）。
纯中文散文可被高估约 45%，所以对外该引用后者。运行时行为这一版不动（会改召回条数，属 v0.7）。

## 升级注意

- **存储布局不变**，旧库不需要 rebuild。
- `compileContext()` 新增 `suppressed` 字段；`reembed()` 的返回值多了 `inflight`，
  并删掉了从未使用的 `batch` 参数（如果你传过它，删掉即可，本来也没生效）。
- `resolveModel()` 的匹配顺序变了（别名 → 单向前缀 → 厂商家族）。**未知模型的价格从 0 变成最贵档**——
  如果你的预算上限很紧，之前"看起来免费"的模型现在可能被裁剪，这是修正而不是回归。

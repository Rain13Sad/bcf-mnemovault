# v0.5.0 — 让决策链真的会出手

v0.4 造好了保留度的骨架：七因子、六道闸、六档处置、逐级降档。它的问题是**不动**。

实测：10 条普通用户陈述，访问时间推到 400 天前，跑 5 次降档 pass——移动 **0 条**。
被取代的"我们用 vitest"仍然拿 P4（0.716），与当前值（P5，0.750）几乎同权。
同一条记忆被召回 20 次、没有任何新证据，confidence 从 0.775 漂到 0.950。

一句话总结 v0.4 的实际行为：**对用户说过的话——不删、不归档、不降档，无论它多琐碎、多过时、多重复。**

这一版修的是这条链路上的每一环。

---

## 一、三个缺陷叠在一起，让整条链路失效

| 缺陷 | 具体形态 | 后果 |
| :--- | :--- | :--- |
| **恒真闸** | 第五道闸判据是 `trust >= 240 && provenance === 0`，而 `TRUST_BY_PROVENANCE[0]` **就是 240**。更糟的是闸用 `score = max(score, floor)` **改分** | 对 100% 用户输入恒真，七因子评分被整体架空 |
| **静态因子不随时间贬值** | 七个因子里六个（重要度/情绪/关联/叙事/锚定/间隔）是静态量，只有 ACTR 激活随时间变 | 400 天旧陈述仍拿 0.73（P4），时间几乎不影响结论 |
| **逐级降档 × 闸 floor** | 一次 pass 只移动一级（合理，防抖动），闸又保底 P3 | `1 → 2` 之后永远停在冷层，到不了归档，更到不了墓碑 |

修法是把三件事拆开：

1. **闸不改分，只封顶**——分数永远由公式给出，闸只负责"不许进墓碑"。
2. **加陈旧包络**——`score × (0.15 + 0.85·clamp01(1 − (days−30)/700))`，30 天不折损，730 天到地板。
3. **闸加必要条件**——一手事实要 `support ≥ 3 || accessCount ≥ 3`，随口一句不再受保护。

## 二、其余八处

| 之前 | 现在 |
| :--- | :--- |
| `tInvalid` 在召回/合并/抽象三处被消费，**唯独决定生死的地方不看它** | 失效超过 30 天宽限期 → 强制归档，闸失效；`doctor --fix` 迁移存量库 |
| `SUPERSEDES` 读反方向，保护的是**新值** | 读 `dst`（被取代者）；"版本链环节"闸直接删掉 |
| P1 与 P2 都映射到 tier 3，"墓碑"只存在于文档 | **tier 4 = 墓碑**，不参与召回，面板可复活 |
| 库只进不出 | 墓碑压实释放残差（≈ 存储的 47%）与向量，保留行、摘要、血缘 |
| 召回抬高 confidence | 召回只加固稳定性；置信度只由证据推动 |
| `recall()` 写库，面板刷新就算"使用" | `readOnly` 召回 |
| URL token 脱敏依赖被切掉的 `?` 锚点 | 脱敏提到切分之前，规则也接受行首/空白锚点 |
| lockfile 只锁一个 esbuild 平台包 | 删掉从未使用的 esbuild；lockfile 平台中立；CI 加 npm@latest 矩阵 |

## 三、补了 v0.4 路线图里两项（选择性地）

- **睡眠选择性重放（M2）**：巩固期把"30 天未访问、已掉到 tier ≥ 2、保留度仍 ≥ 0.45"的记忆抬回一级。
  降档必须能双向——只降不升，重要但久未提及的记忆会一路滑到墓碑。
- **Gross 情绪调节 + 特质层（M3）**：`AffectPolicy.regulation` 五策略选一条；
  `affect.trait` 从人格锚与关系模型**投影**，不单独存储（否则会出现双真相）。

```
测试      135 → 151 全绿
基准      Recall@8 0.941 · MRR 0.681 · 存储比 0.839 · p95 13ms（门槛全过，未改打分公式）
实测      10 条用户陈述 400 天后：移动 10/10（v0.4 是 0/10）
          900 天后：5 条进墓碑，字节 10945 → 9994，残差 5 → 0
          20 次召回：confidence 漂移 0.000

```

## 五、兼容性与代价

- **存储布局不变**（MC03），旧库不需要 rebuild。tier 4 用 tier 字段（u8），不占 flag 位。
- **行为变化是用户可见的**：旧事实会归档、随口琐事会降档、被取代的旧值不再占热层。这是目的，不是副作用。
- **墓碑不可展开原文**：压实释放残差，复活只能拿回摘要与槽位。这是字节回收的代价，也是"墓碑"的本义。
- **闸只封顶**意味着会出现"分数 P1 / 处置 P2"的记忆，面板两栏都显示并给出理由。

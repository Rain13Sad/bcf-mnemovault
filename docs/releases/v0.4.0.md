# v0.4.0 — 让「遗忘」和「情绪」变成机制

v0.3 有两处说不清的地方：

- **为什么这条该留、那条该走？** 判据只有 `tAccess`——一条被确认过十次的事实，
  和一条只说过一次的同龄记忆，遗忘曲线完全相同。
- **为什么难过的事会被忘掉？** 情绪事件只是一个带半衰期的数组，没有状态。
  于是"我没接住"和"我安慰过了"在架构上完全一样。

0.4 换掉这两处。它们不是实现细节，而是**没有机制**；补上机制之后，两件事都能被测试断言。

---

## 一、保留度：七因子 + 六档 + 六道闸

```
score = 0.5 + gain · ( Σ wᵢ·xᵢ − bias )
```

`x` 是七个 0..1 的量：**ACT-R 激活**（频率 + 近因）、重要度、情绪强度、关联度、
叙事角色、用户锚定、间隔效应，减去**冗余**惩罚。

ACT-R 的 `B = ln Σ (t_now − t_j)^(−0.5)` 是这条公式的核心：它天然是幂律，与原来的
`R(t) = (1+Ft/S)^(−0.5)` 形状一致，所以可以无缝替换，同时把"提过几次"这件事纳进来。

| 档 | 阈值 | 动作 | 可逆性 |
| :--- | :--- | :--- | :--- |
| P5 保持 | ≥ 0.75 | 热层，完整向量 + 残差 | — |
| P4 压缩 | ≥ 0.55 | 温层，向量降为 PQ32 | 可解压 |
| P3 摘要化 | ≥ 0.35 | 冷层，只留槽位 + digest | 需 replay |
| P2 归档 | ≥ 0.18 | 归档层 | 可恢复 |
| P1 墓碑 | < 0.18 | 只留 id + digest + 理由 | 可复活 |
| P0 物理删除 | — | **永不自动执行** | 不可逆 |

**六道"永不删除"的闸**优先于任何分数：用户 pin、情感记忆、人格锚、关系里程碑、
用户亲口所述的一手事实、版本链环节、仍被其他记忆引用。

> 实现时踩过一个坑：初版把闸门写成"保底 P4"，结果每条用户发言（都是 `provenance=0`）
> 都永远温热，六档退化成两档。现在普通闸门保底 P3、情感记忆保底 P4，
> 并且 pin 直接跳过整条降档流程。

## 二、再巩固：提取会改写记忆

```
dS   = reinforce(S, R, Δt) − S                 // 测试效应
dConf = plastic ? −0.08·predErr : +0.02         // 被纠正 → 记忆变软
dVal  = 0.05·congruence·(1−|v|)                 // 心境一致性
labile = max(0.05, 1/(1+ln(1+accessCount)))     // 反复提取后硬化
```

这解释了两件 0.3 解释不了的事：**为什么越聊越深**（稳定性单调上升）、
**为什么会被带偏**（预测误差大时置信度下降）。

预测误差的触发点是 `ingest()` 的冲突检测——"用户改主意"是目前唯一确定"新信息与旧记忆不符"的时刻。
`predictionErrorProxy()` 已实现但未接线，README 里标为代理量，不假装是真预测误差。

## 三、情绪事件：五态状态机

`open → acknowledged → attended → resolved / dormant`

三条硬规则：

1. **未获回应的情绪不衰减**：`open` 时强度 `peak + 0.05·ln(1+Δt/H)`，只增不减。
2. **开放事件占独立高优先槽**，不参与 4±1 竞争。
3. **反漠视**：效价 < −0.3 或存在未平复事件 → 策略强制 `requireAcknowledgment`、
   禁止发散、至少问一句。

情绪分类是 OCC 的**纯函数**子集（22 类里判据互斥的那些），不调 LLM——
情感逻辑不能被模型随机性污染，和"写入可复现"是同一条理由。

## 四、神经调制：四个标量，只做全局增益

DA δ / ACh / NE / CORT 全部由已有量算出，只作用于编码初值、图跳数、检索温度。
**不改打分公式**——这是本版本唯一能安全引入类脑机制的位置，bench 基线不受影响。

## 五、面板：横屏优先

`@container (min-width: 760px)` 把顶部页签换成左侧导航栏 + 双列内容，窄于 760 px 自动退回。
判据是**容器自身宽度**而不是视口宽度——同一个组件可能被塞进 320 px 侧栏，也可能全屏 1440 px。

新增「保留度」页：六档分布、逐条七因子柱状分解、四信号与检索温度、再巩固日志。
旧快照（没有 `retention` 字段）降级为说明页，不会白屏。

## 六、修复

- `resolveByPrefix` 不再全表扫描：`Store.findByPrefix()` + `substr(cell_id, 9)` 表达式索引。
- `KIND_LABEL` 补上 `6: 叙事`（v0.3 漏了，面板上显示成"事实"）。
- `demoteDue` 只在 tier 真的变化时写库。

## 兼容性

- **存储布局不变（MC03）**，旧库不需要 rebuild。
- `PanelSnapshot.retention` 与 `AffectPolicy.requireAcknowledgment` 都是**可选字段**。
- 唯一的行为变化：`demoteDue()` 的判据换了。同一批数据在 0.4 下可能降得比 0.3 慢
  （因为频率与情绪进入了公式），这是设计意图。

## 测试

115 → **135** 条，全绿。新增 20 条覆盖：ACT-R 单调性、"重要但不常提"90 天后仍在 P4 以上、
情感记忆拉回热层、六道闸逐条命中、逐级降档、再巩固的置信度下降与硬化、
神经调制的图跳数与温度、"同一天说三遍不算规律"、未回应情绪强度上升、
前缀查询（内存 + SQLite）、面板快照带保留度。
